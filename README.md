<h1>Lightspeed</h1>
Lightspeed was a passion project of mine I worked on as part of the Fontys curriculum. 
My goal with this project was to learn the basics of unity, C# and game design by making a platformer focused on precision and speed. 
As this was a solo project, I was responsible for every part: no AI was used during this project.
